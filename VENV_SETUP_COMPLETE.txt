NEXT STEPS - BEFORE YOU CAN LOG IN
================================================================================

You need to set up AWS Cognito for authentication. Edit .env with:

  COGNITO_DOMAIN=your-pool.auth.us-east-1.amazoncognito.com
  COGNITO_CLIENT_ID=your-client-id
  COGNITO_CLIENT_SECRET=your-client-secret

To get these values:

1. Go to: https://console.aws.amazon.com/cognito/v2/idp/user-pools
2. Create a new User Pool named "AI-Assurance-Lab"
3. Configure:
   - Sign-in method: Email
   - User verification options: Email (automatic)
4. Create an app client:
   - App type: Web
   - Callback URLs: http://localhost:5000/auth/callback
   - Sign-out URLs: http://localhost:5000/logout
5. Copy the Client ID and Secret to .env

See README.md for detailed Cognito setup instructions.

================================================================================
TROUBLESHOOTING
================================================================================

"command not found: python3"
  → Install Python 3.11+
  → Run: brew install python@3.11 (on Mac)

"venv: No such file or directory"
  → Run: python3 -m venv venv

"ModuleNotFoundError"
  → Activate venv: source venv/bin/activate
  → Reinstall: pip install -r requirements.txt

"ENCRYPTION_KEY not configured"
  → .env file has been created with a key
  → Make sure you're in the project directory

"Cognito authentication failed"
  → Check COGNITO_* variables in .env
  → Verify Cognito User Pool exists
  → Check callback URL is exactly: http://localhost:5000/auth/callback
