================================================================================
SECURITY ARCHITECTURE
================================================================================

Token Encryption Flow:
  1. Student enters token on /credentials page
  2. Token encrypted with: Fernet(HMAC-SHA256(ENCRYPTION_KEY + email))
  3. Encrypted token stored in DynamoDB
  4. On API call, encrypted token retrieved
  5. Decrypted using same email context
  6. Decrypted token used only to call external APIs
  7. Never exposed to frontend or logs

Per-User Isolation:
  - Student A's encrypted token requires Student A's email to decrypt
  - Student B cannot decrypt Student A's token (different context)
  - Each student's data completely isolated

Session Security:
  - HttpOnly session cookies (no JavaScript access)
  - Secure flag set in production
  - 7-day session duration
  - Session cleared on logout

API Security:
  - All endpoints validate user from session (never from request)
  - DynamoDB queries scoped by user email
  - Credentials never logged or exposed in error messages
