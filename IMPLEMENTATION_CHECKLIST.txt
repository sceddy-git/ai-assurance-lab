STEP 1: LAUNCH EC2 (5 minutes)
[ ] Open AWS Console → EC2 → Instances
[ ] Click "Launch Instances"
[ ] Set Name: ai-assurance-lab
[ ] Select OS: Ubuntu 22.04 LTS
[ ] Select Instance Type: t3.small
[ ] Create/select SSH key pair
[ ] Configure security group:
    [ ] Allow SSH (port 22) - for setup only
    [ ] Allow HTTP (port 80) - for web access
    [ ] Allow HTTPS (port 443) - for production
[ ] Launch instance
[ ] Wait for "running" status (2-3 min)
[ ] Copy Public IPv4 address: ________________________________
[ ] Note EC2 instance ID: ________________________________

STEP 2: SSH & RUN SETUP (5 minutes)
[ ] Open terminal/command prompt
[ ] SSH: ssh -i your-key.pem ubuntu@YOUR_IP
[ ] Verify: See ubuntu@ip-xxx:~$ prompt
[ ] Run: curl -fsSL https://raw.githubusercontent.com/YOUR_REPO/ai-assurance-lab/main/ec2-setup.sh | bash
[ ] Wait for script to complete (~5 min)
[ ] Verify: See "✅ Flask running on port 5000" message
[ ] Note lab URL: http://YOUR_IP
[ ] Exit SSH: exit

STEP 3: CONFIGURE VIA WEB PORTAL (5 minutes)
[ ] Open browser
[ ] Visit: http://YOUR_IP
[ ] Log in with Cognito account (may need to set password first)
[ ] Click "Settings" link (top right)
[ ] Go to "Configuration" tab
[ ] Enter Cognito Domain: ________________________________
[ ] Enter Client ID: ________________________________
[ ] Enter Client Secret: ________________________________
[ ] Enter Proctor Emails: ________________________________
[ ] Generate Encryption Key (instructions in portal)
[ ] Paste Encryption Key
[ ] Click "Save Configuration"
[ ] Wait for Flask to restart (5 seconds)
[ ] Verify: Settings → System Status shows "✓ Running"

STEP 4: UPLOAD STUDENTS (1 minute)
[ ] Click "Students" link (top right)
[ ] Prepare CSV with format: email, first_name, last_name
[ ] Drag CSV onto upload area (or click to browse)
[ ] Verify: Results show "Created: X, Failed: 0"
[ ] Check: Student list appears in table below

STEP 5: SHARE & LAUNCH
[ ] Copy lab URL from browser
[ ] Share with students: http://YOUR_IP (or custom domain if set up)
[ ] Students log in with Cognito email
[ ] Students access AI Assurance Lab!
