================================================================================

✅ User-Configurable Credentials
   - Each student manages their own ThousandEyes & Meraki tokens
   - Encrypted per-user in DynamoDB
   - Never exposed to frontend plaintext

   - HttpOnly secure cookies

================================================================================
ENCRYPTION FLOW
================================================================================

Add Token:
  1. Student enters token
  2. Token encrypted with: Fernet(HMAC-SHA256(KEY + email))
  3. Encrypted token stored in DynamoDB

Use Token:
  1. Encrypted token retrieved from DynamoDB
  2. Decrypted using student's email context
  3. Decrypted token used for API call
  4. Never exposed to frontend or logs

Delete Token:
  1. Encrypted token removed from DynamoDB
  2. Status marked disconnected
  3. No recovery possible (by design)
