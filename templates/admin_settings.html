Getting Started

  1. Configure Cognito settings in the Configuration tab
  2. Add your email to Proctor Emails
  3. Generate and paste an encryption key
  4. Click Save Configuration
  5. Flask will restart automatically
  6. Go to Students tab to upload student list

Common Tasks

  • View Logs: Click Logs tab to see application errors
  • Restart App: Status tab → Restart Flask App button
  • Deploy Changes: Deployment tab → Pull Latest Code
  • Upload Students: Click Students link at top
  • Check System: Status tab shows CPU, memory, uptime

Troubleshooting

  • Students can't log in: Check Cognito configuration
  • Credentials not working: Check encryption key is set
  • App crashed: Check logs, then restart Flask
  • Need to update code: Use Deployment tab → Pull Latest
